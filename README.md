# ⚡️ Telegram-бот моніторингу енергосистеми багатоквартирних будинків (Deye Cloud + ДТЕК)

Масштабована асинхронна система моніторингу інверторів **Deye**, акумуляторних батарей (АКБ), роботи ліфтів та насосів для ОСББ / керуючих компаній. Адміністратор підключає єдиний мастер-акаунт **Deye Cloud OpenAPI**, а мешканці будинків проходять верифікацію за номером квартири та отримують доступ до живого статусу, графіків та розумних сповіщень.

---

## 📋 Аналіз архітектури та реалізований функціонал

1. **Єдиний мастер-акаунт Deye Cloud (`app/services/deye_api.py`)**:
   - Авторизація за SHA-256 хешем пароля (`/v1.0/account/token`) із кешуванням токена в Redis.
   - Автоматичне отримання списку всіх будинків/станцій (`/v1.0/station/list`) та телеметрії по кожній станції (`/v1.0/station/latest` + `/v1.0/device/latest` для трифазної напруги `L1 / L2 / L3`).
   - Вбудований режим симуляції (`DEYE_MOCK_MODE=true`) для тестування та демонстрації без реального обладнання.
2. **Розумний фоновий моніторинг (`app/services/monitor.py`)**:
   - Опитування хмари кожні 5 хвилин (`POLL_INTERVAL_SECONDS=300`), запис історії в MySQL та кешування в Redis.
   - **Зникнення світла**: фіксація переходу на АКБ, підрахунок тривалості попереднього періоду зі світлом, звірка з графіком ДТЕК (планове чи аварійне відключення) та прогноз часу роботи ліфта до порогу `20%`.
   - **Повернення світла**: підрахунок тривалості відключення, перевірка напруги по 3 фазах (норма `207–253 В`). Якщо напруга просіла або завищена — надсилається захисна інструкція:
     > *«Щоб не вибило автомат в ТП - НЕ ВМИКАЄМО потужні електроприлади, чекаємо 5-10 хвилин»*.
   - **Стабілізація напруги**: окреме сповіщення, коли напруга повертається в межі `207–253 В`.
   - **Критичний розряд АКБ (`<= 20%`)**: попередження про вимкнення ліфта для збереження живлення насосів.
3. **Візуальна аналітика (`app/services/charts.py`)**:
   - Генерація PNG-дашборду (`matplotlib`):
     1. Динаміка заряду АКБ (SOC %) за 24 години з лінією критичного рівня ліфта `20%`.
     2. Графік потужності споживання будинку (кВт) за 24 години.
     3. Стовпчикова діаграма тривалості відключень по днях за останні 7 днів.

## 🚀 Посібник із розгортання (Ubuntu Server + Docker Compose)

### Крок 1. Підготовка облікових даних
1. **Telegram Bot Token**:
   - Відкрийте [@BotFather](https://t.me/BotFather) у Telegram, виконайте `/newbot` та скопіюйте токен.
   - Дізнайтеся свій Telegram ID (наприклад, через [@userinfobot](https://t.me/userinfobot)), щоб вказати його в `ADMIN_IDS`.
2. **Deye Cloud OpenAPI**:
   - Зареєструйте застосунок на порталі розробника [Deye Cloud Developer](https://eu1-developer.deyecloud.com/) та отримайте `DEYE_APP_ID` і `DEYE_APP_SECRET`.
   - Використовуйте `DEYE_EMAIL` та `DEYE_PASSWORD` від вашого мастер-акаунту, до якого прив'язані інвертори будинків.
   - *(Опційно)* Для тестового запуску без ключів Deye залиште `DEYE_MOCK_MODE=true`.

### Крок 2. Встановлення Docker на Ubuntu Server
```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y ca-certificates curl gnupg git
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER
newgrp docker
```

### Крок 3. Клонування проєкту та налаштування `.env`
```bash
git clone <URL_ВАШОГО_РЕПОЗИТОРІЮ> TelegramBotElekrtro
cd TelegramBotElekrtro
cp .env.example .env
nano .env
```

Заповніть `.env`:
```env
BOT_TOKEN=7123456789:AAH_ваш_реальний_токен
ADMIN_IDS=123456789

MYSQL_HOST=mysql
MYSQL_PORT=3306
MYSQL_USER=deye_user
MYSQL_PASSWORD=strong_password_here
MYSQL_DATABASE=deye_monitor
MYSQL_ROOT_PASSWORD=strong_root_password_here

REDIS_HOST=redis
REDIS_PORT=6379

DEYE_BASE_URL=https://eu1-developer.deyecloud.com
DEYE_APP_ID=ваш_app_id
DEYE_APP_SECRET=ваш_app_secret
DEYE_EMAIL=master@osbb.ua
DEYE_PASSWORD=ваш_пароль_deye
DEYE_MOCK_MODE=false

POLL_INTERVAL_SECONDS=300
ELEVATOR_CRITICAL_SOC=20.0
VOLTAGE_MIN=207.0
VOLTAGE_MAX=253.0
TIMEZONE=Europe/Kyiv
```

### Крок 4. Запуск через Docker Compose
```bash
docker compose up -d --build
```
Перевірка логів роботи бота та фонового воркера:
```bash
docker compose logs -f bot
```
Під час старту контейнер автоматично виконує міграції `alembic upgrade head`, синхронізує список станцій із Deye Cloud та запускає фоновий моніторинг.

## 💻 Локальний запуск для розробки (без Docker)

1. Створіть віртуальне середовище та встановіть залежності:
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\activate
   pip install -r requirements.txt
   ```
2. Скопіюйте `.env.example` у `.env` та вкажіть параметри локального MySQL і Redis (`MYSQL_HOST=localhost`, `REDIS_HOST=localhost`).
3. Виконайте міграції бази даних:
   ```powershell
   alembic upgrade head
   ```
4. Запустіть бота:
   ```powershell
   python -m app.main
   ```

## 📖 Посібник із застосування (Інструкція користувача та адміністратора)

### 1. Робота Адміністратора
Адміністраторами вважаються користувачі, чиї Telegram ID вказані у змінній `ADMIN_IDS`.
- `/admin` — Відкриває панель адміністратора зі списком підключених будинків, їхніх `station_id` у Deye Cloud, черг ДТЕК та кількістю нових заявок від мешканців.
- `/sync_houses` — Примусово синхронізує всі станції з мастер-акаунту Deye Cloud у базу даних MySQL.
- `/add_house <station_id> | <Назва будинку> | <Черга ДТЕК>` — Додає або оновлює будинок і його чергу ДТЕК вручну. Приклад:
  ```text
  /add_house 1049281 | Будинок №61 | Черга 5.1
  ```
- `/pending` — Виводить усі нерозглянуті заявки мешканців із кнопками **«✅ Підтвердити доступ»** та **«❌ Відхилити»**.
- Під час кожної нової заявки мешканця адміністратор миттєво отримує повідомлення в чат із інтерактивними кнопками схвалення.

### 2. Онбординг та команди Мешканця будинку
1. **Реєстрація (`/start` або `/join`)**:
   - Мешканець натискає `/start`, обирає свій будинок зі списку (наприклад, `🏢 Будинок №61`) та вводить номер квартири (`64` або `12а`).
   - Бот надсилає запит адміністратору. Після натискання кнопки «✅ Підтвердити доступ» мешканець отримує повідомлення про активацію.
2. **Перевірка стану (`/status`)**:
   - Показує наявність світла, стан за графіком ДТЕК, трифазну напругу (`L1 / L2 / L3 В`), поточний заряд батарей (`SOC %`), потужність заряджання/розряджання (`кВт`), споживання будинку (`кВт`), статус ліфта та розрахунковий час до критичного порогу `20%`.
3. **Графік ДТЕК (`/schedule`)**:
   - Виводить планові слоти відключень на сьогодні й завтра для черги будинку з позначкою поточного стану.
4. **Історія за тиждень (`/history`)**:
   - Детальний лог усіх відключень за останні 7 днів із тривалістю та зміною заряду АКБ (наприклад: `10.11 13:17–20:49, 7 год 32 хв • заряд 97% → 59%`).
5. **Графіки (`/charts`)**:
   - Генерує та надсилає в чат PNG-інфографіку із трьома графіками: заряд батарей за добу (з червоною лінією порогу ліфта 20%), потужність споживання будинку в кВт та стовпчикова діаграма тривалості відключень по днях за тиждень.
6. **Персональні сповіщення (`/settings`)**:
   - Дозволяє індивідуально вмикати або вимикати сповіщення про світло, перепади напруги та критичний розряд батарей.
7. **Зміна будинку (`/leave`) та Зворотний зв'язок (`/feedback`)**:
   - `/leave` скидає прив'язку до квартири/будинку, а `/feedback` передає повідомлення про помилку безпосередньо адміністратору.
